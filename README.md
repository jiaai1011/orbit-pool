# 一杆入袋 · ORBIT Pool

公开的浏览器台球游戏，手机触屏和电脑鼠标均可游玩。单机 / 同屏双人，无账号、无联网对战、无服务端数据。

- 同屏黑八：全色/双色分组、自由球、指定黑八袋口、犯规判罚。
- 开球前在线后拖白球，松手自动摆好；出杆前可重新拖动。拖动力度条，松手出杆；右侧精调瞄准。
- 可视化击球点：高低杆、左右塞同步显示球杆偏移和白球标记，支持跳杆、扎杆。拖击球点松手即生效，每杆结束恢复中杆。
- 大袋口与圆形袋角碰撞、开球计算优化、缓存绘图。
- 实录台球声，来源与 CC0 授权见 docs/assets/SOURCES.txt。

## 开发

浏览器适配层在 src/browser.js。src 中的游戏逻辑从微信版移植，玩法和物理参数保持一致。低杆现在按出球速度标定力度，保留轻微偏心损失；不再预先扣除约三分之一的速度。低杆使用两阶段手感辅助：碰球前降低倒旋阶段的拖拽，首次碰目标球或碰库后恢复正常摩擦耦合，由剩余倒旋产生回拉。未碰球不会凭空倒退，薄球保留切线走位。这是游戏操作手感的调整，不是严格统一摩擦系数的真实台球模型。

运行 `node build.cjs` 生成 dist，复制到 docs 后通过 GitHub Pages 发布 main/docs。普通 HTTP 静态托管即可；无第三方运行库和外部字体。

网页链接没有微信预览码的定时失效机制。访问仍依赖 GitHub Pages 服务与仓库保持启用。

## 50 关挑战

入口：欢迎页「挑战 50 关」，或球局菜单中的「挑战之路」。五章各 10 关：初见球感、白球走位、折线思维、连贯清台、大师试炼。共 150 星，逐关解锁，可重试和刷星。进度保存在当前浏览器/微信本机，清除存储后不会保留，不跨设备同步。

固定关卡包含指定袋、白球停区、目标球先碰库、白球先碰库、按序清台和黑八收官。每关标准杆数内三星，多一杆两星，最后一杆一星；白球落袋、顺序错误、指定袋或特殊条件不满足会失败。全部 50 关均有实际物理引擎验证的三星解法，测试用解法不进入网页资源。

- `node tests/challenge.cjs`：50 关可解性、评分、解锁、存档和失败条件。
- `node tests/controller-challenge.cjs`：50 关完整出杆/结算流程和界面命中范围。
- `node tests/draw-calibration.cjs`：近中远低杆、组合塞、速度与倒旋自然衰减。
- `scripts/generate-levels.cjs` 为离线关卡制作工具。修改物理后如需重新校准关卡，可运行它并重新测试；不在玩家设备上搜索打法。

设计参考：
- [Billiard University 基础练习](https://billiarduniversity.org/documents/BU_Exam-I_Fundamentals.pdf)：渐进练习、进球与白球落区目标。
- [Dr. Dave 低杆物理](https://drdavepoolinfo.com/FAQ/draw/physics-advice/)：倒旋随路程衰减、击球速度与低杆效果的关系。

关卡布局、评分与界面为本游戏自行设计，不复制参考资料的图表。

低杆物理改动后，可运行 `node scripts/recalibrate-draw-solutions.cjs` 重新验证现有落区目标的测试解法；不会改变关卡球位、目标区或玩家存档。
