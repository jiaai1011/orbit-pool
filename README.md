# 一杆入袋 · ORBIT Pool

公开的浏览器台球游戏，手机触屏和电脑鼠标均可游玩。单机 / 同屏双人，无账号、无联网对战、无服务端数据。

- 同屏黑八：全色/双色分组、自由球、指定黑八袋口、犯规判罚。
- 开球前在线后摆位；拖动力度条，松手出杆；右侧精调瞄准。
- 高低杆、左右塞、跳杆、扎杆，每杆结束恢复中杆。
- 大袋口与圆形袋角碰撞、开球计算优化、缓存绘图。
- 实录台球声，来源与 CC0 授权见 docs/assets/SOURCES.txt。

## 开发

浏览器适配层在 src/browser.js。src 中的游戏逻辑从微信版移植，玩法和物理参数保持一致。当前版本保留上一版低杆参数；低杆衰减反馈尚未重新调参。

运行 `node build.cjs` 生成 dist，复制到 docs 后通过 GitHub Pages 发布 main/docs。普通 HTTP 静态托管即可；无第三方运行库和外部字体。

网页链接没有微信预览码的定时失效机制。访问仍依赖 GitHub Pages 服务与仓库保持启用。
